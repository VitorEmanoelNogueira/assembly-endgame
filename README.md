# Assembly: Endgame

A word-guessing game built with React as part of Bob Ziroll's Scrimba React course.

## Features

- Guess the hidden word one letter at a time.
- Track incorrect guesses and remaining attempts.
- Win or lose based on the remaining attempts.

## Additional Improvements

- Component-based architecture.
- Extended screen reader support with additional announcements and focus management beyond the original course implementation.
- `aria-pressed` states for keyboard buttons.
- Responsive layout.

## Technologies

- React
- JavaScript
- CSS
- Vite
